# SEO.txt — Search Engine Optimization Notes for Sagar Lad

## Site identity
- Title: Sagar Lad | Author · Investor · Educator
- Description: Practical frameworks on money, career, life and awareness — from the author, investor and educator Sagar Lad.
- Primary language: en-IN
- Canonical domain: https://sagarlad.com

## Keyword focus
Primary: personal finance, money management, career advice, awareness, productivity, self-improvement
Secondary: investing, books, entrepreneurship, life lessons

## On-page SEO
- Every page has a unique title and meta description via Next.js Metadata API.
- Blog posts use semantic heading hierarchy (h1 → h3) and readable slugs.
- Images use descriptive alt text and lazy loading; hero uses priority.
- Mobile-first responsive layout (no duplicate mobile content).

## Technical SEO
- robots.txt generated from app/robots.ts (blocks /admin).
- sitemap.xml generated from app/sitemap.ts (dynamic blog + books URLs).
- llms.txt served at /llms.txt for LLM crawlers.
- Static assets cached; security headers set via proxy.ts.
- Fast load: next/image, font display swap, no render-blocking JS.

## Structured data
- FAQ / Article schema can be added per-post via the Metadata API (openGraph + twitter).
- Books pages can embed Book schema for rich results.

## Content best practices
- Publish original, in-depth articles on money/career/life.
- Interlink blog ↔ books ↔ newsletter for internal link equity.
- Use descriptive slugs matching the primary keyword.
- Keep meta descriptions under 160 characters.

## Monitoring
- Submit sitemap.xml in Google Search Console.
- Track Core Web Vitals (LCP < 2.5s, INP < 200ms, CLS < 0.1).
